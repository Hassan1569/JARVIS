# UI/UX Design — JARVIS

## 1. Visual Direction
Professional AI productivity tool. Calm, focused, information-dense without clutter. Sci-fi **hints** — not sci-fi costume.

## 2. Palette
| Token | Hex | Use |
|---|---|---|
| `bg-base` | `#0B1220` | App background (dark navy) |
| `bg-panel` | `#111A2E` | Panels, cards |
| `bg-elevated` | `#16223B` | Input fields, hover |
| `border` | `#22304F` | Dividers, outlines |
| `text-primary` | `#E6ECF5` | Main text |
| `text-muted` | `#8A99B5` | Secondary text |
| `accent` | `#22D3EE` | Cyan highlight (used sparingly) |
| `accent-dim` | `#0E7490` | Pressed state |
| `success` | `#22C55E` | OK status |
| `warning` | `#F59E0B` | Caution |
| `danger` | `#EF4444` | Errors, destructive |

## 3. Typography
- Primary: **Inter** (fallback: Segoe UI, system-ui).
- Mono: **JetBrains Mono** (fallback: Consolas) for logs/tool output.
- Sizes: 12 (meta), 14 (body), 16 (title), 20 (h1).
- Line-height 1.5. No letter-spacing except uppercase labels (+0.05em).
